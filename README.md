# CodeAlpha_Chatbot
FoodApp FAQ Bot

A smart, interactive FAQ bot for food apps built using Python Flask and a clean web interface. Users can select common questions from a dropdown menu, and the bot instantly provides answers using a simple AI-powered backend.

🚀 Features

Interactive Dropdown UI – Users select questions from a styled dropdown.

Instant Responses – Answers appear immediately without page reloads.

AI-Powered Backend – Python Flask app matches user questions to predefined FAQs.

Clean & Responsive Design – Gradient background, cards, and styled response box.

Expandable – Can integrate more AI/NLP capabilities using spaCy or other ML models.

💻 Technologies Used

Frontend: HTML, CSS, JavaScript

Backend: Python, Flask

Libraries: spaCy (for future NLP improvements)

🌟 Future Improvements

Integrate more advanced NLP for better understanding of user queries.

Add voice interaction for hands-free assistance.

Connect to a real food app backend to fetch dynamic order data.

Make UI fully responsive for mobile and tablet screens.
